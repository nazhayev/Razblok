# 🔓 Разблокировка банковских карт — Официальные методы 2026

Интерактивный веб-сайт с пошаговыми инструкциями по разблокировке банковских карт ведущих банков России.

## 🌐 Демо

Откройте `index.html` в браузере или разверните на GitHub Pages.

## 🏦 Поддерживаемые банки

- Сбербанк
- Тинькофф
- ВТБ
- Альфа-Банк
- Газпромбанк
- Райффайзен

## 📋 Типы блокировок

| Тип | Сложность | Описание |
|-----|-----------|----------|
| 🔒 Неверный ПИН-код | Просто | 3 ошибки → блок на 24ч |
| 📅 Истёк срок | Просто | Перевыпуск карты |
| 👤 Заблокировал сам | Просто | Утеря, кража, временная |
| 🛡️ 115-ФЗ | Сложно | Финмониторинг |
| ❄️ 161-ФЗ | Средне | Период охлаждения |
| ⚖️ Арест ФССП | Сложно | Судебные приставы |
| 💳 Просрочка | Средне | Долг по кредиту |

## 📥 Скачиваемые материалы

Для каждого типа блокировки доступны:
- Пошаговые инструкции (PDF)
- Образцы заявлений (DOCX)
- Чек-листы документов
- Жалобы в ЦБ РФ

## 🚀 Развёртывание на GitHub Pages

1. Создайте новый репозиторий на GitHub
2. Загрузите `index.html` в корень репозитория
3. Перейдите в **Settings → Pages**
4. Выберите ветку `main` и папку `/ (root)`
5. Сайт будет доступен по адресу `https://ваш-ник.github.io/название-репо/`
